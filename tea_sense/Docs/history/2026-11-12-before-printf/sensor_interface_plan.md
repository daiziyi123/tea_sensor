# H743单板传感器接线与CubeMX配置对照

> 本文保留硬件接口规划。2026-11-12 当前代码已完成三层迁移，原 SoilAdc_Read 对应 BspAdc_ReadRaw / SensorSoil_Read，仍只采 AD0；代码结构和本次构建验证见 [代码架构](code_architecture.md) 与 [重构交付](refactor_report.md)。本文后续多传感器流程尚未实现。

适用工程 tea_sense，芯片 STM32H743VIT6，LQFP100。编制日期 2026年11月12日。风速与风向以本次实物铭牌为准；雨量采用用户确认的两线干接点版本。

建议采用稳压24 V供电，四路电压采集加一路雨量计数和两路百叶箱RS485。保留已经跑通的AD0土壤水分和USART2电脑输出。下表是后续接线和CubeMX配置的推荐分配，本次未改动固件或.ioc。[1][2]

| 对象 | 板卡端子 | MCU与外设 | 输入规格 |
| --- | --- | --- | --- |
| 土壤水分 | AD0 / AIN0 | PB1 / ADC1 INP5 | 0～5 V → 0～100% |
| 风速 GH-FS | AD2 / AIN2 | PA6 / ADC1 INP3 | 0～5 V → 0～30 m/s |
| 风向 GH-FX | AD3 / AIN3 | PA5 / ADC1 INP19 | 1～5 V → 0～360° |
| 土壤 pH | AD4 / AIN4 | PA4 / ADC1 INP18 | 0～5 V → pH 3～9 |
| 雨量 干接点 | X0 / IN0 与外部0 V | PE15 / EXTI15 | 一次闭合计一次翻斗 |

### 为何保留AD1不用

AD1在原理图接PB0，而U21接收输出也标PB0；另一处串口指示灯与引出端又标PE0，存在图纸内部不一致。未经实物通断核对，不让pH占用AD1，改用AD4。四路ADC通道编号是5、3、19、18，与端子编号0、2、3、4分别对应，不能把AD编号直接当ADC通道号。[2]

百叶箱按用户要求使用两路独立RS485，统一放在相邻的第三、四路。按旧代码，环境参数路读取温湿度、光照、气压、PM2.5/10，另一组读取CO₂/O₂；具体线束分工以实物标签为准。两组A/B线各接一路，不把它们并成同一总线。[2][8][12]

## 1 统一24 V供电及各传感器适配

在已确认的输出版本下，板卡、土壤水分、pH、风速、风向和百叶箱均有24 V供电依据。雨量为无源干接点，不作为24 V供电负载。24 V是供电电压，模拟量输出的0～5 V或1～5 V量程保持不变。

| 设备 | 供电依据 | 24 V结论 |
| --- | --- | --- |
| H743板卡 | JP3标12～24 V，LM2596S降至5 V [2] | 符合输入标注 |
| 土壤水分 | 现有RE-SD-V05-TR标签10～30 V [4] | 符合 |
| 土壤pH | 说明书10～30 V，照片勾选10～30 V [3][4] | 符合 |
| 风速GH-FS | 本次实物铭牌24 VDC [5] | 符合额定供电 |
| 风向GH-FX | 本次实物铭牌24 VDC [6] | 符合额定供电 |
| 百叶箱ST-BYX | 说明书9～24 V [8] | 符合，处于上限 |
| 雨量两线干接点 | 用户确认无源开关输出 | 不直接供电 |
| 独立CO₂/O₂设备 | 只有旧串口读取代码，缺实物供电参数 | 暂不接入24 V |

### 电源分配

24 V正极经适当支路保护分别接板卡JP3正端和有源传感器电源正；0 V接板卡电源负和传感器电源负。板内标为+24V的电源网络来自输入，不会把12 V自动升成24 V。切换电源前断电，使用电表核对极性及空载、带载电压，再逐个接入。百叶箱和板卡的标注上限为24 V，不采用输出明显偏高的“24 V”电源。[2][8]

模拟量信号负端要回到AD接口GND。RS485的参考地接所用端子的GNDG；GNDG与MCU GND在图上经0 Ω配置连接，实际隔离方式需按实装确认。外接独立电源时不直接并联两个电源的正极。百叶箱两组通信线若同属一台ST-BYX可沿用该主机供电；若第二组来自独立模块，需先按该模块额定值供电，不能由“两路485”推断它也允许24 V。[2][8]

### 电源容量

GH-FS通用资料列电压型最大功耗300 mW；pH列0.4 W但测试条件为12 V。百叶箱功耗随选配模块变化，风向铭牌没有额定电流，因此现有资料不足以精确计算整机电流。按各实物额定功耗合计并留余量，逐支路测量启动和稳定电流后确定电源容量。[3][5][8]

### 每路增益分别确认

| 端子 | 串联电阻 | ADC节点对地电阻 | 输入端对地支路 |
| --- | --- | --- | --- |
| AD0 | R46 10 kΩ | R6 值重叠待确认 | R68 标100 Ω |
| AD2 | R48 10 kΩ | R36 值重叠待确认 | R70 标100 Ω |
| AD3 | R49 10 kΩ | R39 值重叠待确认 | R156 标100 Ω |
| AD4 | R50 10 kΩ | R40 值重叠待确认 | R157 标100 Ω |

若确认是纯电阻分压，G=(R上+R下)/R下，传感器电压=ADC引脚电压×G。R下图中文字4.7K与3.3K重叠，不能擅自选择147/47或133/33；四路也不能未经核对就共用同一增益。[2]

100 Ω输入对地支路若实装，会在5 V下吸收约50 mA、耗散0.25 W，可能使电压型传感器输出被拉低。必须先确认这些支路是否安装及实际阻值。D6等钳位支路不能替代分压保护，传感器电压不能直接接MCU引脚。[2]

断电并断开传感器后核对电阻实装；上电后用已知稳定电压同时测端子与ADC节点，按V端子/V引脚计算增益，并用多个电压点检查线性。接近0 V时不适合求比例。参考源VREF+对VREF−单独实测，不能由24 V供电值推算。

## 3 CubeMX的ADC配置

沿用现有ADC1和单次轮询采样方式，扩展PA6、PA5、PA4。建议保持每次只转换Rank 1的一路，由后续应用在停止状态下切换通道，避免未经配套改写就开启四Rank扫描。[1][2][13]

| 配置项 | 建议值 |
| --- | --- |
| PB1 | ADC1_INP5，Single-ended，Label SOIL_AD0 |
| PA6 | ADC1_INP3，Single-ended，Label WIND_SPEED_AD2 |
| PA5 | ADC1_INP19，Single-ended，Label WIND_DIR_AD3 |
| PA4 | ADC1_INP18，Single-ended，Label PH_AD4 |
| GPIO | Analog，No pull；PA4/PA5不启用DAC输出 |
| Resolution | 16 bits，结果uint16_t，0～65535 |
| Clock Prescaler | Asynchronous clock divided by 8，保留现有时钟来源 |
| Sampling Time | 所有被切换使用的通道均为387.5 cycles |
| Regular转换 | Number of Conversions = 1；Rank 1初始Channel 5 |
| Scan / Continuous / Discontinuous | 均Disable |
| 触发 | Software Start；无外部触发边沿 |
| EOC与数据 | End of single conversion；DR；无左移 |
| Oversampling / DMA / ADC IRQ | 均不启用 |
| 低功耗自动等待 | Disable；保留现有Overrun Data Preserved |

### 生成代码后需要配套的采样流程

初始化后执行一次现有H7单端offset及linearity校准。每秒依次处理AD0、AD2、AD3、AD4：停止ADC → HAL_ADC_ConfigChannel指定通道、Rank 1和采样时间 → 检查配置结果 → Start → PollForConversion并设置20 ms超时 → 读值 → Stop。逐级保留错误状态，失败输出NA。

CubeMX界面中启用多个输入引脚，不等于应用已经能采四路；保持Regular只有一个Rank。若界面自动增加Rank或生成扫描配置，应恢复上述方案后再生成。当前SoilAdc_Read不切换通道，多传感器代码须显式选择通道，并保证下一次土壤采样前已恢复Channel 5，否则会把其他传感器当成土壤水分。不能仅改.ioc后直接运行现有单路业务。[1]

## 4 电压及物理量转换

所有公式的U均为还原后的传感器输出电压，单位mV。先算adc_pin_mV=raw×VREF_mV/65535，再算U=adc_pin_mV×GAIN_NUM/GAIN_DEN。固件可合并乘除以减少中间舍入，乘法用足够宽的整数。不要使用旧ADS1115的0.1875系数或补码处理。

| 对象 | 当前确定的映射 | 计算式 |
| --- | --- | --- |
| 土壤水分 | 0～5000 mV → 0～100% | ratio=U/5000；pct=U/50 |
| 风速GH-FS | 0～5000 mV → 0～30 m/s | v=U×30/5000 m/s |
| 风向GH-FX | 1000～5000 mV → 0～360° | θ=(U−1000)×360/4000 |
| 土壤pH | 0～5000 mV → pH 3～9 | pH=3+U×6/5000 |

| 项目 | 低端 | 中点 | 高端 |
| --- | --- | --- | --- |
| 水分 | 0 mV → 0% | 2500 mV → 50% | 5000 mV → 100% |
| 风速 | 0 mV → 0 m/s | 2500 mV → 15 m/s | 5000 mV → 30 m/s |
| 风向 | 1000 mV → 0° | 3000 mV → 180° | 5000 mV → 360° |
| pH | 0 mV → 3 | 2500 mV → 6 | 5000 mV → 9 |

### 与旧系统的区别

风速旧代码用32.4 m/s为满量程，本次GH-FS实物铭牌为30 m/s，应以30为准；沿用32.4会高算8%。风向旧式与铭牌1～5 V一致；pH原式3+1.2×电压V也与0～5 V对应3～9一致。旧系统AD5、AD6、AD7只是旧ADC板的接口编号，不用于本板ADC通道或新数组下标。[5][6][11]

### 状态与量程

VREF未实测时保留EST。分压未确认时仅输出原始值与ADC引脚估算电压，U及物理量为NA。风向U小于1000 mV或大于5000 mV先标超量程，不能用无符号减法得到大数或直接钳位为0°。ADC失败与有效0值分开。

初次验证均不启用滤波。风向0°与360°等价，只有通过量程检查后才可按显示约定归一化；安装时按机械北向标记校准。以后若平均风向，不能直接对359°和1°作算术平均。

## 5 百叶箱两路485的接线和CubeMX设置

按用户要求使用两路独立RS485，选同一组6位端子J1上的A3/B3与A4/B4，接线集中，保留A2/B2给电脑。旧代码环境路与CO₂/O₂路各用一个串口、均为4800及地址1；两路分开时地址1可各自保留。[2][8][12]

| 接线或配置 | 设置 |
| --- | --- |
| 传感器电源 | 红接24 V；黑/蓝接0 V |
| 环境路RS485 | 第一组A接A3、B接B3；ST-BYX黄A、绿B，部分批次灰替黄 |
| 第二路RS485 | 第二组A接A4、B接B4；不同模块线色按自身线束标签 |
| 板卡参考地 | 传感器电源负接本路GNDG，确认地连接方式 |
| 第三路CubeMX | USART3 Asynchronous，PD8 TX / PD9 RX，AF7；U6/U13 |
| 第四路CubeMX | UART4 Asynchronous，PC10 TX / PC11 RX，AF8；U14/U17 |
| 帧格式 | 8 data bits，No parity，1 stop bit，No flow control |
| 波特率与地址 | 旧设备先核对4800、地址1；手册出厂9600、地址1 |
| NVIC / DMA | 初次短帧轮询可不启用；接收必须有超时 |

J1原理图引脚1～6依次为B4、GNDG、A4、B3、GNDG、A3；实物方向按丝印核对，不凭照片左右猜位置。两路均TX and RX。USART3不选PC10/PC11，避免占用UART4的接线引脚。两路使用各自UART句柄与接收缓冲区，不混合帧。[2][13]

| 寄存器地址 | 项目 | 换算与单位 |
| --- | --- | --- |
| 0x0000 / 0x0001 | 湿度 / 温度 | 各÷10；%RH / ℃ |
| 0x0002～0x0003 | 光照度 | 高字<<16加低字，lux |
| 0x000B | 气压 | ÷10为hPa，÷100为kPa |
| 0x0014 / 0x0015 | PM2.5 / PM10 | 原数值，μg/m³ |
| 0x0007 / 0x0008 | CO₂ / O₂ 选配 | ppm / 原数÷10为% |

环境路读0x0000/0002/000B/0014，第二路按旧设备读0x0007/0008；以各模块实际支持项为准。这些是0基地址，不发送PLC的40001。功能码03，数据高字节在前、CRC低字节在前；初次采用300 ms应答超时及不小于300 ms的相邻请求间隔。检查地址、长度、CRC、异常帧；负温编码另核对，不能照搬旧无符号解析。[8][12]

## 6 雨量干接点的接线和CubeMX设置

本项目采用用户确认的两线干接点/脉冲输出，不采用GH-04手册里的有源RS485接法。两根线构成一个无源开关，不能把24 V正负直接跨接在这两根线上。机械翻斗说明的0.2 mm/次作为初始分辨率，仍需通过实际翻斗次数核验。[7]

| 位置 | 接法或设置 |
| --- | --- |
| 输入公共端COMX+ | 接外部24 V正极；先核对实物端子标识 |
| 雨量第一根线 | 接板卡X0 / IN0 |
| 雨量第二根线 | 接外部24 V电源的0 V |
| 输入信号路径 | COMX+ → R74 → LED23 → OP11 → IN0 → 干接点 → 0 V |
| MCU信号路径 | OP11输出 → PE15，板上R79 4.7 kΩ上拉至3.3 V |
| 闭合时逻辑 | 光耦导通，PE15为低；断开为高 |
| CubeMX引脚 | PE15 = GPIO_EXTI15；Label RAIN_PULSE |
| GPIO设置 | External Interrupt Mode with Falling edge；No pull |
| NVIC | Enable EXTI line15:10 interrupt；仅计数和记录时间 |
| 软件处理 | 每个有效闭合计1次；主循环读取计数快照 |

### 去抖与换算

先用万用表通断档在断电状态确认两线开闭，再接板卡并观察PE15是否一次翻斗只产生一个有效事件。去抖可先试50 ms时间门限，并用实测脉宽与抖动修正；回调内不执行延时、串口发送或其他传感器读取。不能对持续低电平反复计数。

累计降雨量mm=N×0.2。区间雨强mm/h=(N结束−N开始)×0.2×3600/T秒；例如5分钟内10次翻斗，区间雨量2 mm，平均雨强24 mm/h。累计量与雨强是不同字段。旧代码用低电平循环计数并乘6，不能作为本板的换算依据。[7][12]

COMX+供电会影响同一公共端下的其他输入，应核对这些输入当前连接。使用光耦现场侧回路，不把24 V直接送到PE15；EGND输出端与AD GND也不能只凭名称互换。本次不占用额外定时器通道。

### 方向控制保持与串口分离

图上有自动收发电路，也有GPIO经0 Ω电阻接方向节点。现有USART2保持AUTO，不驱动方向GPIO。新增USART3和UART4先确认实际装配及应答波形，不因CubeMX可选DE就启用硬件流控或输出GPIO。尤其第四路RE4与电脑第二路RE2都可能经0 Ω连接PD3，不能擅自驱动。手动模式须隔离自动电路并确认电平，以TC确认最后停止位完成才切回接收。[2]

| GPIO | 图中共用方向节点 | 涉及0 Ω电阻 |
| --- | --- | --- |
| PD3 | RE2、RE4、RE7 | R120、R144、R167 |
| PD4 | RE1、RE5、RE8 | R121、R145、R168 |
| PB7 | RE3、RE6 | R125、R146 |

PD3、PD4还接数字输出光耦输入，PB7还用于24C02的I²C数据线。未核对装配时均不设为方向输出。USART1另经JP4在RS485与板载CH340之间选择；USART8接收网名冲突未解决前不用。A/B网络上的120 Ω终端电阻按实装和总线两端位置核对，不随意额外叠加。[2]

图中全部串联电阻标10 kΩ；下拉阻值存在4.7K/3.3K重叠；输入负载均标100 Ω。该表是图纸网络关系，不能代替实物装配确认。PC2_C是该封装真实名称，不能把图中PC2字样直接认成ADC1 Channel 12。AD8经R66到PC0，旁边单独出现的PC3文字没有同一根连线，不能据此把AD8配置成PC3。[2][13]

### 必须在接线前区分的三类编号

第一类是板卡端子AD0、AD2等；第二类是MCU管脚PB1、PA6等；第三类是ADC通道INP5、INP3等。软件索引由新工程自行定义，推荐固定记录名称与通道表。旧板AD7的土壤传感器在新工程已经是AD0，不能以旧接口编号推断新数组位置。[1][10][11]

### 本次发现的图纸不一致

U20/U21附近写UART3/UART4，实际PE8/PE7与PE1/PE0分别对应UART7/UART8。U21的Voa输出标PB0，与ADC AD1冲突，须查实物是否应为PE0。pH因此选AD4。RS485方向电阻按图应为PD3经R144连RE4，R145属于PD4连RE5，不沿用此前记录中相反的编号。

这些事项未通过修改原理图或固件自行消除。用万用表在断电时核对目标焊盘与引脚通断，并确认板卡版本与PDF一致；不在未确认节点上直接施加电压。
